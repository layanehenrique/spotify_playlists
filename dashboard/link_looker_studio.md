# Dashboard — Curadoria Editorial de Playlists no Spotify

🔗 [Acessar o dashboard no Looker Studio](https://datastudio.google.com/reporting/cb713889-17cd-494d-944a-75b61d4a4f06/page/81E5F)

## Sobre este dashboard

Construído no Google Looker Studio, apresenta o diagnóstico completo sobre o valor da curadoria editorial de playlists, estruturado em blocos:

1. **Curadoria gera valor?** — correlação playlist x streams, mediana por faixa de playlist
2. **Chart e multiplataforma** — presença em chart x streams, presença multiplataforma, correlação Spotify x Shazam
3. **O que mais influencia o sucesso** — gênero, país, número de artistas, época de lançamento
4. **Próximos passos** — recomendações e dados necessários para medir causalidade
